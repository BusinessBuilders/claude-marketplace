# Worked example: Open Source Must Win — Shopify store graphics

Five standalone SVGs produced with this skill (dark editorial brand, hand-built vector,
literal colors, xmlns + escaped font imports — see references/svg-illustration.md):

1. `01-hero-open-source-must-win.svg` (1400×560) — hero banner: git-branch graph merging into a star
2. `02-uniform-kit.svg` (1000×560) — tee/hoodie/cap product-kit illustration
3. `03-closed-vs-open.svg` (1000×560) — manifesto: closed padlock box vs open contributor network
4. `04-built-by-builders.svg` (1000×560) — workshop cutaway with code/hardware/robots rooms
5. `05-trust-badges.svg` (1200×160) — footer trust strip

Designed for dark backgrounds. Render to PNG for raster upload with headless Chrome
(`--force-device-scale-factor=2`, +110px window-height slack, crop to exact size).
